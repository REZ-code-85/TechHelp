# Techhelp

موقع تقني ثابت يدعم العربية والإنجليزية والفرنسية.

## المميزات
- صفحات HTML مستقلة لكل قسم.
- الصفحة الرئيسية وصفحة 404.
- صفحات المقالات وعن الموقع واتصل بنا وسياسة الخصوصية.
- بحث محلي في المقالات.
- تصميم متجاوب للهاتف والكمبيوتر.
- لا يحتاج إلى حزم Python إضافية.

## التشغيل المحلي
افتح موجه الأوامر داخل مجلد `Techhelp` وشغّل:

    python -m http.server 8000

ثم افتح:

    http://localhost:8000

## النشر
ارفع محتويات مجلد Techhelp إلى GitHub، ثم فعّل GitHub Pages من إعدادات المستودع.

## إضافة المقالات
أضف المقالات في `assets/data/articles.json` مع الحقول:
- id
- category
- title: ar, en, fr
- description: ar, en, fr

استخدم إحدى قيم category التالية:
programs, windows, tutorials, ai, cybersecurity, tools, networks, android

## تنبيه
نموذج الاتصال تجريبي ولا يرسل الرسائل إلى خادم. يلزم ربطه بخدمة خلفية عند إطلاق الموقع.
المقالات الحالية أمثلة أولية ويجب استكمال محتواها قبل النشر الرسمي.
